## 2025-06-28 - Escape Dynamic Identifiers in SQL Queries
**Vulnerability:** SQL injection vulnerability found in `src/server/internal/migration/validator.go` due to unescaped dynamic identifiers (`tableName` and `pkColumn`) interpolated directly into `fmt.Sprintf` calls for database queries.
**Learning:** Standard SQL parameters (`$1`, `$2`, etc.) cannot be used for identifiers like table names or column names, which can lead developers to mistakenly use direct string interpolation (`fmt.Sprintf`), exposing the application to SQL injection. Furthermore, importing driver-specific packages like `github.com/lib/pq` simply for utility functions can introduce blocking side effects (like driver registration panics) and make the code incompatible with other databases.
**Prevention:** Use standard string manipulation (e.g., `strings.ReplaceAll(tableName, "\"", "\"\"")`) or driver-agnostic safe mechanisms to manually escape and quote dynamic SQL identifiers before interpolating them into query strings in Go, avoiding unnecessary external driver dependencies.
