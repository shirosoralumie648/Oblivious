## 2024-08-30 - Insecure Client IP Extraction
**Vulnerability:** The Go backend securely extracts client IPs from the `X-Forwarded-For` header in some places by taking the right-most IP (`parts[len(parts)-1]`), but in other places (like `extractIP` in `channel_service.go`, `requestClientIP` in `admin_handler.go`, and `clientIP` in `tenant_handler.go`) it incorrectly uses the first index (`parts[0]`). This allows a malicious client to easily spoof their IP address by supplying a fake IP in the `X-Forwarded-For` header, which could bypass IP-based rate limiting, access controls, or pollute audit logs.
**Learning:** When behind a trusted edge proxy (like AWS ALB or Nginx), the proxy appends the true client IP to the end of the `X-Forwarded-For` header list. The first entry (`parts[0]`) is fully user-controlled and untrustworthy.
**Prevention:** Always extract the right-most (or strictly validated right-most non-internal) IP from the `X-Forwarded-For` header to ensure trustworthiness.
