## 2025-02-23 - DataTable Unnecessary Computations on Re-renders
**Learning:** Shared components like `DataTable` that take large datasets in props (e.g. admin analytics panels) were unnecessarily recomputing derived state (like mapping/filtering rows to find valid selectable IDs) on *every* render cycle. Because selection changes (`selectedIds` updating on checkbox click) trigger a re-render of the entire table, `O(2N)` map-filters were executing blocking the main thread during simple click interactions.
**Action:** When a shared list/table component processes a `data` prop for rendering or derived state, explicitly wrap iterations spanning the full array in `useMemo` (and collapse chained operations like `.map().filter()` into `.reduce()` for a single pass). Ensure dependencies strictly reflect the original data (e.g., `[data]`) and *not* fast-changing state like `selectedIds`.
