## 2025-05-18 - Avoid unnecessary object creation in React component default props\n**Learning:** Instantiating objects or arrays in React component default prop definitions (e.g. `selectedIds = new Set<string>()`) breaks memoization and causes unnecessary re-renders when other state changes.\n**Action:** Create an empty constant (e.g. `const EMPTY_SET = new Set<string>();`) outside the component and use that as the default prop value.
