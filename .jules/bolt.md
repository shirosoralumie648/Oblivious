## 2024-06-08 - Optimized DataTable to prevent unnecessary re-renders\n**Learning:** The DataTable component was computing 'selectableRows' and checking selection counts on every render via O(n) operations over the 'data' array, even when the 'selectable' prop was false (the default state). React's lack of automatic memoization for complex prop derivations can quickly bloat render times if table rows get large.\n**Action:** Use useMemo to wrap O(n) map/filter logic inside heavily-reused components like DataTable, combined with an early exit (if !selectable return empty arrays). Also wrap handler functions passed to child components in useCallback.
