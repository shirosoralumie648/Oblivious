## 2023-10-27 - Added loading spinners to MCP Servers Panel buttons
**Learning:** Providing visual feedback during asynchronous operations significantly improves perceived performance and user confidence, especially for tasks that might take a moment, like network requests or tool executions. Replacing static icons with spinners on disabled buttons is a clean, non-disruptive way to achieve this.
**Action:** Consistently apply this pattern across the application whenever a button triggers an asynchronous action and has a corresponding loading state available.
