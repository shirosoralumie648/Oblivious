## V3 Product Gap Themes

1. Evidence spine gap: Relay, Chat, RAG, Agent, Workflow, Billing, Observability, and Admin need one shared request/run/trace/usage identity model.
2. Route honesty gap: unsupported surfaces must be explicit disabled product states, not implied roadmap completion.
3. Ledger gap: Relay usage records now carry immutable price snapshots, but billable paths still need provider-sourced price import/audit and reconciliation.
4. Runtime durability gap: RAG ingestion, workflow transitions, agent tool steps, and batch-like long flows must survive restart.
5. Admin enforcement gap: frontend dashboards are not proof of backend RBAC.
6. Scope gap: local OAuth bridges, desktop/PWA, Kubernetes/Envoy, full marketplace, and full visual workflow are reference-rich but not P0.
