# Vertical Slice Gap Report

Date: 2026-07-02

Scope: Oblivious production runtime only. Reference projects were not used to decide whether Oblivious flows exist. Scores are end-to-end product-flow scores, not API-count scores.

Subagent reconciliation note: the dedicated vertical-slice subagent scored several flows higher because it emphasized that real UI/API/DB paths exist. I kept the lower scores below where the user-specified audit rules require stricter treatment: no fake/local fallback, no missing external integration, no missing billing/quota effect, no memory-only debug state, and no missing target-runtime evidence. In short: "real code exists" is recorded, but it is not enough to raise a flow above the caps when the product flow is not fully closed.

## Flow Breaks Ranked

1. Gateway proxy now forwards into Relay, but still needs target-runtime provider/request-log/usage evidence.
2. Chat production fallback is closed, but target-runtime live provider/request-log/usage evidence is still missing.
3. RAG upload now enqueues durable raw-payload ingestion jobs with status UX, but target Postgres/Qdrant worker recovery and retrieval-debug evidence are still missing.
4. RAG vector intent now covers document create/update, chunk edit/split/merge, and delete cleanup transactionally, but target Postgres/Qdrant recovery proof and retrieval-debug evidence are still missing.
5. Marketplace payout is fail-closed without a configured provider and uses a repository-local transactional dispatch outbox/retry ledger, but target external payout/reconciliation proof is still missing.
6. Relay realtime lacks auth/billing/settlement in handler paths and is disabled by policy.
7. Relay batch lacks prebill/polling/settlement and is disabled by policy.
8. Workflow SQL node execution trace/snapshot rows are durable, repository-local replay/prune APIs now exist, and release proof requires counted workflow telemetry, but target DB-backed replay/prune and telemetry source proof are not complete.
9. Workflow service-level pause/resume/cancel transitions now use a durable StateMachine sink; trigger replay/idempotency and full retry/failure replay depth remain incomplete.
10. Agent custom Python has a configured Docker sandbox path, but lacks target-runtime isolation/log/cancellation/artifact proof.
11. Agent streaming is not provider/tool streaming in structured path.
12. Relay pricing authority now uses a SQL catalog, fails closed on missing prices, and persists immutable request price snapshots; remaining gap is provider price-source audit/import and reconciliation evidence.
13. Observability production request-log sink is fail-closed and release proof can now fetch runtime SLO delivery/recovery details, but target ClickHouse row proof and request-id joins are still missing.
14. Alert delivery depends on configured sinks; missing sinks are now persisted as failed delivery attempts, and target evidence still must prove nonzero SLO alerts, zero delivery failures, and persisted recovery audit records.
15. Secretbox rejects plaintext legacy secrets in production, and target secret-audit proof now requires checked timestamp plus nonzero scan summary with zero plaintext/invalid/rotation-required counts; real target rotation and audit evidence remain.
16. Marketplace review automation is deterministic and auditable locally, but still lacks external risk signals and target reviewer evidence operations.
17. Non-Stripe payment providers are unconfigured by default.
18. OpenAI-compatible surface breadth is ahead of commercial lifecycle implementation.
