# Agent Final Stream Callback Completion Guard

Date: 2026-07-04

## Runtime Claim

Agent ReAct runs no longer overwrite a completed durable run as `failed` when final-answer streaming to the client fails after the assistant message and run completion have already been persisted. The client transport error is still returned to the caller, but the run ledger keeps the completed execution state and final message evidence.

## Failure Evidence

The negative path makes `OnChunk` return `client stream closed` after the final assistant message is persisted and `completeRun` has marked the run complete. The test asserts the error returns to the caller while the durable run remains `completed`, has no run error, and keeps `CompletedAt`.

## Unsupported / Deferred Surfaces

- This does not implement true incremental structured tool-call streaming.
- Simple non-tool `RunStream` still has no durable run ledger in this slice.
- Full client-abort cancellation trace, provider abort propagation, and audit-log joins remain commercial-readiness work.

## Known Residual Risk

The final answer is still chunked from an already-complete structured response in ReAct paths. This guard prevents corrupting completed run evidence, but it is not a replacement for end-to-end live provider streaming.
