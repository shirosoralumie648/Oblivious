# Workflow State Replay Invalid Transition Guard

Date: 2026-07-04

## Runtime Claim

Workflow state replay now marks unsupported durable status transitions as invalid instead of presenting them as a valid replay. This closes a replay-integrity gap where a corrupted or manually inserted event such as `running -> queued` could previously appear as `Valid: true` with an empty replay event.
