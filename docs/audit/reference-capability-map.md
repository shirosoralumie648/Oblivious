# Reference Capability Map

Date: 2026-07-02

Scope: read-only capability extraction from `reference/` projects plus the already returned reference-audit subagents. This file is not proof that Oblivious implements a capability. It is a target-depth map for what production Oblivious needs before any completion claim is credible.

Scoring rules used downstream: schema/API/tests alone cap a feature at 2/5; no user-visible runtime flow caps it at 2/5; no real external integration caps it at 3/5; mocks, fake providers, fake checkout, fake payout, fake telemetry, hardcoded pricing/states, TODO paths, and local-only shortcuts are incomplete.
