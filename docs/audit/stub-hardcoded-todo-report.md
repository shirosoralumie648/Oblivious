## Tests Ahead Of Production Implementation

The audit did not score tests, but several implementation patterns indicate tests/OpenAPI/matrix can be ahead of runtime:

- Gateway proxy tests validate session-to-Relay forwarding, but commercial completion still needs target-runtime provider evidence and request-log joins.
- Relay policy advertises/defines many `/v1/*` classes while policy disables commercial functionality for realtime/batch/fine-tuning/assistants/threads/runs.
- Chat UI/API can pass with a local demo generator if Relay is not required.
- Workflow debug APIs now have a durable trace/snapshot store path from SQL node executions plus state-replay and debug-retention prune endpoints, but repository-local tests still do not prove target Postgres restart replay/prune behavior.
- RAG tests validate parser/chunk/retrieval, document-scoped Qdrant cleanup, update-time vector replacement, title-bearing vector payload contracts, vector index job retry/dead-letter behavior, transactional vector intent enqueue for document create/update, chunk edit/split/merge, delete cleanup, and parsed-content ingestion job retry/dead-letter behavior, but do not yet prove raw upload parser replay or target Postgres/Qdrant recovery.
- Marketplace paid install can create orders/settlements without target live payout rail proof; repository-local payout creation fails closed without a provider and dispatches only after local ledger commit.
