## 2026-07-20 - Add ARIA Labels to Pagination
**Learning:** Pagination components benefit significantly from semantic <nav> tags, explicit aria-labels on prev/next buttons, aria-labels for specific pages, and hiding visual spacers like ellipses from screen readers to improve keyboard and screen reader accessibility.
**Action:** Always use <nav aria-label="Pagination"> and provide specific aria-labels for all interactive pagination controls in this app's design system.
