## 2024-09-03 - Pagination Accessibility
**Learning:** Pagination components using generic `div` or `Button` elements need semantic grouping (like `<nav aria-label="Pagination">`) and explicit aria labels (e.g. "Go to previous page") to ensure screen readers can announce the navigation purpose and actions accurately.
**Action:** Add `nav` wrapper and explicit `aria-label` attributes to Pagination components and buttons.
