## 2024-05-18 - [Accessible Pagination Navigation]
**Learning:** Pagination components must use semantic `<nav aria-label="Pagination">` elements, include descriptive `aria-label`s on all navigation buttons, and use `aria-hidden="true"` on visual spacers (e.g., ellipses) to improve screen reader accessibility.
**Action:** Always wrap pagination controls in a `<nav>` with a descriptive aria-label, apply aria-labels to prev/next/page buttons, and hide decorative elements like ellipses from screen readers.
