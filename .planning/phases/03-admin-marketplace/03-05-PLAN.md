   - WHERE a.id = $1
   - Return *PublishedAgent with OwnerName and CategoryName populated

**UpdateAgent(ctx, id, input) (*PublishedAgent, error)** per D-19:
   - UPDATE published_agents SET name=COALESCE($1,name), description=COALESCE($2,description), icon_url=COALESCE($3,icon_url), category_id=COALESCE($4,category_id), tools=COALESCE($5,tools), example_conversations=COALESCE($6,example_conversations), system_prompt=COALESCE($7,system_prompt), visibility=COALESCE($8,visibility), pricing_type=COALESCE($9,pricing_type), pricing_amount=COALESCE($10,pricing_amount), updated_at=NOW()
   - WHERE id = $11
   - If input.Tags changed: DELETE FROM agent_tags WHERE agent_id = $id; re-INSERT
   - Status resets to 'pending_review' per D-19 (each update requires re-review)
   - If input.Version: INSERT new version row
   - RETURNING with JOINs

**DeleteAgent(ctx, id)**:
   - DELETE FROM published_agents WHERE id = $1 (CASCADE deletes versions, reviews, installs)

**ListUserAgents(ctx, ownerID, limit, offset)**:
   - SELECT with JOINs WHERE owner_id = $1 ORDER BY created_at DESC LIMIT/OFFSET

**ListPendingReviews(ctx, limit, offset)** per D-17:
   - SELECT with JOINs WHERE status = 'pending_review' ORDER BY created_at ASC (oldest first — fair queue) LIMIT/OFFSET

**ApproveAgent(ctx, id, reviewerID)** per D-17:
   - UPDATE published_agents SET status = 'approved', reviewed_at = NOW(), review_reason = NULL WHERE id = $1 AND status = 'pending_review'
   - Also UPDATE agent_versions SET status = 'approved' WHERE agent_id = $1 AND status = 'pending_review'
   - Return error if no rows affected (agent not in pending_review state)

**RejectAgent(ctx, id, reviewerID, reason)** per D-17:
   - UPDATE published_agents SET status = 'rejected', reviewed_at = NOW(), review_reason = $reason WHERE id = $1 AND status = 'pending_review'
   - Also reject pending versions: UPDATE agent_versions SET status = 'rejected' WHERE agent_id = $1 AND status = 'pending_review'
   - Return error if reason is empty (rejection reason is required per D-17)

**CreateVersion(ctx, agentID, version, changelog, metadata)** per D-19:

   - Check UNIQUE(agent_id, version) — if duplicate, return error "version already exists"
   - Return *AgentVersion

**ListVersions(ctx, agentID)**:
   - SELECT FROM agent_versions WHERE agent_id = $1 ORDER BY created_at DESC

**GetVersion(ctx, agentID, version)**:
   - SELECT WHERE agent_id = $1 AND version = $2

**InstallAgent(ctx, agentID, userID, versionID)** per D-20:
   - INSERT INTO agent_installs (id, agent_id, user_id, version_id) with uuid
   - ON CONFLICT (agent_id, user_id) DO NOTHING (already installed is OK — idempotent)
   - UPDATE published_agents SET install_count = install_count + 1 WHERE id = $agentID
   - Return *AgentInstall

**UninstallAgent(ctx, agentID, userID)**:
   - DELETE FROM agent_installs WHERE agent_id = $1 AND user_id = $2
   - UPDATE published_agents SET install_count = GREATEST(install_count - 1, 0) WHERE id = $agentID

**ListUserInstalls(ctx, userID)**:
   - SELECT FROM agent_installs WHERE user_id = $1. JOIN agent for name. ORDER BY installed_at DESC.

**IsInstalled(ctx, agentID, userID)**:
   - SELECT EXISTS(SELECT 1 FROM agent_installs WHERE agent_id = $1 AND user_id = $2)

**CreateReview(ctx, userID, input ReviewInput)** per D-27:
   - INSERT INTO agent_reviews (id, agent_id, user_id, rating, body) with uuid
   - ON CONFLICT (agent_id, user_id) DO NOTHING — user can only create one review per agent
   - UPDATE published_agents: SET rating_avg = (SELECT AVG(rating) FROM agent_reviews WHERE agent_id = $1), rating_count = (SELECT COUNT(*) FROM agent_reviews WHERE agent_id = $1)
   - Return *AgentReview

**UpdateReview(ctx, userID, input ReviewInput)** per D-27:
   - UPDATE agent_reviews SET rating = $rating, body = $body, updated_at = NOW() WHERE agent_id = $1 AND user_id = $2
   - Recalculate rating_avg and rating_count on published_agents
   - Return updated *AgentReview

**ListReviews(ctx, agentID, limit, offset)**:
   - SELECT with user name JOIN: `LEFT JOIN users u ON r.user_id = u.id` for UserName field
   - ORDER BY created_at DESC LIMIT/OFFSET

**GetUserReview(ctx, agentID, userID)**:
   - SELECT WHERE agent_id = $1 AND user_id = $2. Return nil if not found.

**ListCategories(ctx)** per D-28:

   - BEGIN TXN. DELETE FROM agent_tags WHERE agent_id = $1. For each tag: INSERT INTO agent_tags VALUES ($1, $tag) ON CONFLICT DO NOTHING. COMMIT.

   - **Full-text search** (D-30): Uses PostgreSQL `to_tsvector` + `plainto_tsquery` against the existing GIN index `idx_published_agents_fts`.
     ```sql
     SELECT a.*, c.name AS category_name, u.name AS owner_name,
            ts_rank(to_tsvector('english', a.name || ' ' || a.description), plainto_tsquery('english', $query)) AS rank
     FROM published_agents a
     LEFT JOIN categories c ON a.category_id = c.id
     LEFT JOIN users u ON a.owner_id = u.id
     WHERE a.status = 'approved' AND a.visibility = 'public'
       AND (to_tsvector('english', a.name || ' ' || a.description) @@ plainto_tsquery('english', $query) OR $query = '')
     ```

   - **Multi-dimensional filters** (D-30):
     - `filter.CategorySlug != ""`: `AND c.slug = $n`
     - `filter.Tags != nil && len > 0`: `AND a.tags && $n::text[]` (PostgreSQL array overlap operator)

     - `filter.Sort == "" || filter.Sort == "relevance"`: `ORDER BY rank DESC, a.rating_avg DESC` (default: text relevance)

     - `"newest"`: `ORDER BY a.created_at DESC`
