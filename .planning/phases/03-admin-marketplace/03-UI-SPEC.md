## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, badge padding |
| sm | 8px | Compact element spacing, form label gap |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding, drawer/modal body padding |
| xl | 32px | Layout gaps, page content max-width padding |
| 2xl | 48px | Major section breaks, hero banner padding |
| 3xl | 64px | Page-level spacing, top-level layout gaps |

Exceptions:
- Icon-only touch targets: 44px minimum (accessibility, matches WCAG 2.5.5)
- Sidebar width: 256px (fixed, not in 8-point scale)
- Status indicator dots: 8px diameter

## Interaction Patterns

### Status Polling (Channels)
- Poll `GET /api/v1/admin/channels/:id/health` every 30 seconds per visible channel
- Visual feedback: dot color transitions (green<->yellow<->red), pulse animation on green
- Latency tooltip updates on each poll cycle
- Stop polling when user navigates away from channels page

### Inline Actions (Tables)
- Actions column: always-visible toggle for Enable/Disable, dropdown menu for Edit/Test/Delete
- Test Connection: inline button, shows spinner during test, result as tooltip (not navigation)
- Batch actions: checkbox column, toolbar appears with count ("3 selected") + batch action buttons

### Search & Filter
- Admin sidebar: keystroke filtering, highlight matching characters, instant results (no debounce needed for small item count)
- User table search: 300ms debounce, query params in URL for shareable filtered views
- Marketplace search: 500ms debounce (full-text backend search), URL query params (`?q=...&category=...&rating=...`)

### Form Submission
- All forms: disable submit button during submission, show spinner, display success/error toast
- Drawer/modal forms: close on success, stay open on validation error
- Confirmation dialogs: trap focus, Escape to cancel, click outside does NOT dismiss for destructive actions

### Install Flow
1. Click "Install Agent" -> button shows spinner
2. `POST /api/v1/marketplace/agents/:id/install` -> returns success
3. Button transitions to "Open Agent" with brief success animation (checkmark pulse)
4. Agent appears in "My Agents > Installed" tab
5. On error: toast with error message, button resets to "Install Agent"

## Accessibility Requirements

- All interactive elements: minimum 44px touch target (WCAG 2.5.5)
- Status indicators: include `aria-label` (e.g., `aria-label="Channel online"`)
- Color is never the sole indicator of state: status dots paired with text labels, chart segments have pattern fallbacks
- Focus management: drawer/modal open traps focus on first focusable element, close returns focus to trigger
- Table sort/filter: announce changes via `aria-live` region
- Star rating: keyboard navigable (arrow keys), announced as "Rate N out of 5 stars"
- Form errors: announced via `aria-describedby` linking inputs to error messages
- Sidebar: `aria-label="Admin navigation"`, current page marked with `aria-current="page"`
- Loading states: `aria-busy="true"` on skeleton regions
