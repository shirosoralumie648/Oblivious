## Threat Model

|--------|----------|-------------------------|

| Local developer workflows become brittle because every local `scripts/test.sh server` run requires Postgres. | Medium | Preserve local explicit skip behavior unless `OBLIVIOUS_REQUIRE_TEST_DATABASE=true` is set. |
| v04 completion is mislabeled as final commercial readiness. | High | Add a commercial gate document that states v04 is foundation only and v05-v08 remain required. |
| Quality gates check docs but not the new commercial gate contract. | Medium | Extend `scripts/verify-quality-gates.sh` to assert the new commercial gate doc and CI required-DB strings. |
| Verification records commands without environment class or migration status. | Medium | Require `12-VERIFICATION.md` to list DB env class, migration status, pass/fail status, skips, and residual commercial work. |
</threat_model>
