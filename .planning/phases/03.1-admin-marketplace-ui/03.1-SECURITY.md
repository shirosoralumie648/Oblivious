# Phase 03.1 - Security

Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Browser to Admin API | Admin UI calls `/api/v1/admin/*`; backend `requireAdmin` is the security boundary. | Admin stats, channels, routes, plans, users, audit logs, reviews, moderation actions |
| Browser to Public Marketplace API | Public marketplace browse/search/detail endpoints are intentionally unauthenticated. | Approved public agent metadata, categories, reviews, versions |
| Browser to Authenticated Marketplace API | Publish/update/install/review/my-agents endpoints require a user session. | User-owned agent drafts, install state, reviews, publisher stats |
| Browser URL to React Router | Frontend `AdminRoute` hides admin pages from non-admin users, but backend RBAC remains authoritative. | Route state and current user role |
| UI Input to API Client | Shared forms, tables, search, and admin/marketplace API clients transform user input before backend validation. | Form values, query filters, JSON payloads |
| API Handler to Service/Store | HTTP handlers decode typed request bodies and delegate business validation to service/store layers. | Validated admin and marketplace mutations |

## Threat Register

| Threat ID | Category | Component | Disposition | Mitigation | Status |
|-----------|----------|-----------|-------------|------------|--------|
| T-3.1-01 | Spoofing | Admin routes | accept | `authMiddleware.requireAdmin` requires a valid session and `admin` role; every `/api/v1/admin/*` route in `router.go` is wrapped by it. | closed |
| T-3.1-02 | Tampering | User update, plan create | mitigate | Handlers decode into typed request structs; plan creation validates required numeric bounds; user updates validate role set, active plan, and self-role changes before store mutation. | closed |
| T-3.1-03 | Information Disclosure | Public marketplace endpoints | mitigate | Public detail/search paths return only `approved` and `public` agents; admin data stays behind `/api/v1/admin/*`. | closed |
| T-3.1-04 | Elevation of Privilege | Install/publish routes | mitigate | Publish, update, install, my-agents, publisher stats, write review, and delete paths route through `requireSession`; service code verifies owner-only update/delete behavior. | closed |
| T-3.1-05 | Denial of Service | Test channel | accept | Channel connectivity tests use an HTTP client with a 5-second timeout. | closed |
| T-3.1-06 | Input Validation | DrawerForm | accept | `DrawerForm` is a layout wrapper that does not parse or trust input; parent pages and backend services own validation. | closed |
| T-3.1-07 | XSS | DataTable, SearchBar | accept | Shared table/search components render through React JSX, coerce primitive cell values, and do not use `dangerouslySetInnerHTML`. | closed |
| T-3.1-08 | Information Disclosure | API clients | accept | Frontend API clients call backend RBAC-protected endpoints; backend middleware decides data authorization before responses are produced. | closed |
| T-3.1-09 | Elevation of Privilege | Admin route access | accept | `AdminRoute` redirects unauthenticated and non-admin users client-side; backend `requireAdmin` remains the authoritative control. | closed |
| T-3.1-10 | Information Disclosure | Client-side stats | accept | Admin dashboard/stat data is fetched from admin-only endpoints guarded by `requireAdmin`; frontend only renders returned data. | closed |
| T-3.1-11 | Tampering | ChannelForm API key field | mitigate | Channel API key input is `type="password"` and edit mode shows a masked placeholder instead of writing the stored secret into the DOM. | closed |
| T-3.1-12 | Denial of Service | Status polling | accept | Channel health polling runs every 30 seconds only while channel data is present and cleans up the interval on unmount/state change. | closed |
| T-3.1-13 | Tampering | Batch enable/disable | accept | Batch channel mutation is a convenience UI path calling an admin endpoint protected by server-side RBAC. | closed |
