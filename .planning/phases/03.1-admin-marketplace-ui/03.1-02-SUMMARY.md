## Deviations

- `createAdminApi().batchUpdateChannels()` accepts `'enable' | 'disable' | boolean` and sends the backend's canonical `{ ids, action }` payload. This matches the implemented Go handler while preserving boolean call-site compatibility.
- Admin and marketplace API factories normalize backend collection payloads such as `{ channels, total }`, `{ routes, total }`, `{ agents, total }`, and `{ categories, total }` into page-friendly return shapes.
- Marketplace install uses the backend route/query spelling `POST /api/v1/marketplace/agents/:id/install?versionID=...`.
