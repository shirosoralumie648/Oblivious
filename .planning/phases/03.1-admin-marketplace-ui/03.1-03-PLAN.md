```typescript
type SidebarGroup = {
```

Default groups:
```
Overview:  [{ label: 'Dashboard', path: '/admin', icon: RiDashboardLine, keywords: ['home', 'stats'] }]
Channels:  [{ label: 'Channels', path: '/admin/channels', icon: RiRouterLine, keywords: ['provider', 'llm', 'api'] }]
Routes:    [{ label: 'Model Routes', path: '/admin/routes', icon: RiGitBranchLine, keywords: ['routing', 'model'] }]
Plans:     [{ label: 'Plans', path: '/admin/plans', icon: RiMoneyDollarCircleLine, keywords: ['pricing', 'subscription', 'tier'] }]
Users:     [{ label: 'Users', path: '/admin/users', icon: RiUserLine, keywords: ['member', 'account'] }]
Audit:     [{ label: 'Audit Log', path: '/admin/audit-log', icon: RiFileListLine, keywords: ['history', 'activity'] }]
Reviews:   [{ label: 'Review Queue', path: '/admin/reviews', icon: RiShieldCheckLine, keywords: ['agent', 'approval', 'moderation'] }]
```

Implementation:
- Use `useLocation()` from react-router-dom to determine active item (exact path match)
- Use `useNavigate()` for navigation (Link component from react-router-dom for accessibility)
- State: `searchQuery` (string), `collapsed` (boolean, default false on desktop, true on tablet/mobile)
- **Search filtering:** When searchQuery is non-empty, filter all items across all groups by label substring match (case-insensitive) and keyword match. Show only matching items, hide groups with no matches. Use instant filtering (no debounce — sidebar has small item count).
- **Active item:** Highlight with `bg-sidebar-primary text-sidebar-primary-foreground` and a left border accent. Add `aria-current="page"` to the active link.
- **Collapsed mode:** Show only icons (no labels). Icons as tooltips. Toggle button at top.
- **Toggle button:** Hamburger icon (RiMenuLine when expanded, RiMenuFoldLine when collapsed) in the sidebar header.
- **Search input placeholder:** "Search modules..." (from UI-SPEC copywriting)
- **Wrapper:** `w-64` (256px) when expanded, `w-16` when collapsed. Transition width. `border-r border-sidebar-border`. `bg-card` background.

Layout structure:
```
<div className="sidebar">
  <div className="sidebar-header">
    {!collapsed && <Input placeholder="Search modules..." />}
    <ToggleButton />
  </div>
  <ScrollArea>
    {groups.map(group => (
      <div>
        {!collapsed && <Separator + group.label />}
        {filteredItems.map(item => (
          <Link to={item.path}>
            {item.icon}
            {!collapsed && <span>{item.label}</span>}
          </Link>
        ))}
      </div>
    ))}
    {noResults && <EmptySearchMessage />}
  </ScrollArea>
</div>
```

Handle all three in a single `Promise.allSettled` or sequential fetch. On error for any, set partial data or error state.
