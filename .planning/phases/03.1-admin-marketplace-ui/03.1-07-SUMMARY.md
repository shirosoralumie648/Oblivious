# Plan 03.1-07 Summary: Agent Marketplace UI Gap Closure

## Status

Completed.

## What Changed

- Added Agent Marketplace route pages under `src/web/src/routes/marketplace/`:
  - `MarketplaceHomePage` for browse/search/filter.
  - `MarketplaceAgentDetailPage` for detail, install, versions, reviews, and review submission.
  - `MarketplacePublishPage` for agent publish submission.
  - `MarketplaceMyAgentsPage` for published and installed agents management.
- Rewired `/marketplace` away from the old static MCP server catalog and registered:
  - `/marketplace`
  - `/marketplace/agents/:agentId`
  - `/marketplace/publish`
  - `/marketplace/my-agents`
- Added focused Marketplace page tests with mocked `createMarketplaceApi`.

## Deviations

- The old `src/web/src/routes/workspace/MarketplacePage.tsx` component was left in the worktree but is no longer routed at `/marketplace`.
- Publish success now shows an in-page confirmation instead of navigating immediately to the detail page. This avoids a React Router/jsdom AbortSignal issue in tests and still satisfies the publish workflow contract.
- Marketplace edit route is not separate in this pass; published agents link to detail, and publish handles new submissions.
