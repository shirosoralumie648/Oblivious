<threat_model>
<threat severity="high" mitigation="Persist `organization_id` on both run tables and require organization filters on every store and HTTP read/write path.">
Agent run state can leak sensitive tool arguments, tool results, memory evidence, or tenant data across organizations.
</threat>
<threat severity="high" mitigation="Approval-required tool runs must be persisted before execution and must return before calling the executor.">
Sensitive tools can execute before human approval if approval is only a UI convention.
</threat>
<threat severity="high" mitigation="Retry must operate on failed/pending records only and must not replay already successful tool calls or duplicate tool result messages.">
Retrying a workflow can duplicate side effects, quota usage, or external tool calls.
</threat>
<threat severity="medium" mitigation="Store redacted/sanitized error state and bounded JSON arguments/results; keep full secrets out of run records.">
Tool arguments and errors can contain credentials or customer data.
</threat>
</threat_model>
