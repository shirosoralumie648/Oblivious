## Threat Model

| Threat | Severity | Mitigation in this plan |
|--------|----------|-------------------------|
| Frontend calls stale or unauthenticated route paths while backend tests pass | High | Cross-check every changed client path against `src/server/internal/http/router.go` and keep calls under `/api/v1/app/*`, `/api/v1/console/*`, or `/api/v1/auth/me`. |
| Session role/name fields drift between backend and UI guards | High | Keep `ApiUser.name`, `ApiUser.role`, and `SessionResponse` typed and used by auth/admin route guards. |
| Raw fetch calls bypass envelope/error handling and cookies | Medium | Route workspace API work through `createHttpClient`; any remaining raw fetch must be documented or replaced. |
| Legacy workspace MarketplacePage installs MCP servers with stale payloads | Medium | Normalize it to the live MCP server contract or mark it as backlog cleanup rather than staging it as active Phase 07 work. |
</threat_model>
