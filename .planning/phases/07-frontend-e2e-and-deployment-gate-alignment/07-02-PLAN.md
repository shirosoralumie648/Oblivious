## Threat Model

| Threat | Severity | Mitigation in this plan |
|--------|----------|-------------------------|
| E2E passes against fixture shapes that do not match the real API envelope | High | Keep fixture responses wrapped as `{ ok, data, error }` and route them through the same `/api/v1/**` paths as the app. |
| Playwright writes generated reports or traces that get staged with source | Medium | Keep generated output outside the commit boundary and verify `git status --short` excludes `test-results`, `playwright-report`, `dist`, and `.tmp`. |
| CI invokes a script name that does not exist in `src/web/package.json` | Medium | Pin `build`, `test`, and `test:e2e` in `src/web/package.json` and mirror them in CI/deployment planning. |
| Browser tests hide auth/admin route regressions with overly broad text queries | Medium | Keep scoped role/heading assertions for admin and marketplace pages. |
</threat_model>
