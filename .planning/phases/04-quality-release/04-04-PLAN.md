## Threat Model

| Threat | Severity | Mitigation in this plan |
|--------|----------|-------------------------|
| Deployment config leaks secrets | High | Use placeholders and `.example` files only; never commit real key values. |
| Deployment stack targets imported `lobehub/` or `new-api/` instead of active mainline | High | Dockerfiles and compose paths must reference `src/server` and `src/web`. |
| Smoke script reports success before server is actually healthy | Medium | Poll `/healthz` with timeout and exit non-zero on failure. |
</threat_model>

  <action>
  Create Dockerfiles for the active mainline:
  - `Dockerfile.server`:
    - Use a Go 1.22+ builder stage.
    - Build `./src/server/cmd/server` into `/out/oblivious-server`.
    - Optionally build `./src/server/cmd/migrate` into `/out/oblivious-migrate`.
    - Runtime stage exposes `8080` and runs `/usr/local/bin/oblivious-server`.
    - Include a `HEALTHCHECK` that curls `http://127.0.0.1:8080/healthz` if curl is available, or document why healthcheck is handled by compose/k8s.
  - `Dockerfile.web`:
    - Use Node 20 with pnpm 10.6.0/Corepack.
    - Install root workspace deps with frozen lockfile.
    - Run `pnpm --dir src/web build`.
    - Serve built assets from a small static server or nginx.
  - `.dockerignore`:
    - Exclude `.git`, `.tmp`, `node_modules`, `lobehub/node_modules`, `new-api`, `.worktrees`, and build outputs.
  </action>
  <acceptance_criteria>
  - `Dockerfile.server` contains `src/server/cmd/server`.
  - `Dockerfile.server` contains `EXPOSE 8080`.
  - `Dockerfile.web` contains `pnpm --dir src/web build`.
  - `.dockerignore` contains `node_modules`.
  - `.dockerignore` contains `.worktrees`.
  - `.dockerignore` contains `new-api`.
  </acceptance_criteria>
</task>

  <action>
  Create `scripts/deploy-smoke.sh`:
  - `set -euo pipefail`.
  - Accept `BASE_URL="${BASE_URL:-http://127.0.0.1:8080}"`.
  - Poll `${BASE_URL}/healthz` up to 30 times with 2-second sleeps.
  - Print `[deploy-smoke] healthz ok` on success.
  - Exit non-zero and print the final URL on failure.
  Update `docs/release/rc-checklist.md` with deployment commands:
  - `docker compose build`
  - `docker compose up -d`
  - `BASE_URL=http://127.0.0.1:8080 bash scripts/deploy-smoke.sh`
  - `kubectl apply -f deploy/kubernetes/namespace.yaml`
  - `kubectl apply -f deploy/kubernetes/`
  - Note that `deploy/kubernetes/secret.example.yaml` must be copied and filled outside git before real cluster use.
  </action>
