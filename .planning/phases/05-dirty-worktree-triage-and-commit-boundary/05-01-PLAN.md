<threat_model>
## Threat Model

| Threat | Severity | Mitigation in this plan |
|--------|----------|-------------------------|
| Accidental staging of user-owned source with planning artifacts | High | Use explicit path lists only; final commit must stage only Phase 5 planning/state files. |
| Deleting or reverting untracked source while trying to clean the repository | High | Phase 5 commands are read-only and must not run `git clean`, `git reset`, or checkout-based cleanup. |
| Misclassifying historical docs as active implementation | Medium | Inventory root historical docs and `docs/superpowers/*` separately from contract docs. |
| Leaking secrets from env files or docs | High | Read only templates/docs required by context; do not inspect real secret-bearing `.env` files; record env var names/placeholders only. |
| Losing the v03.2 restricted-network deployment baseline | Medium | Preserve the exact `OBLIVIOUS_IMAGE_REGISTRY_PREFIX`, `OBLIVIOUS_GOPROXY`, and `OBLIVIOUS_GOSUMDB` command in the handoff. |
</threat_model>
