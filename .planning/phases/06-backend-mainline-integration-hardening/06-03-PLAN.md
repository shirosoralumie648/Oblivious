<threat_model>
## Threat Model

| Threat | Severity | Mitigation in this plan |
|--------|----------|-------------------------|
| App requests quietly bypass Relay when Relay is enabled | High | Make the router choose a fail-closed fallback in production and keep Relay metadata on every model call path. |
| Relay loses user/workspace/request attribution | High | Add metadata merge helpers and HTTP request-id bridging before the service layer calls the gateway. |
| Structured tool calls regress into plain-text only responses | High | Preserve `StructuredReplyGenerator` and assert `RunWithTools` still serializes tool calls and `tool` role messages. |
| Word-level streaming or usage recording breaks while metadata is added | Medium | Keep the existing streaming and usage recording tests in the same package-level regression suite. |
</threat_model>
