<threat_model>
## Threat Model

| Threat | Severity | Mitigation in this plan |
|--------|----------|-------------------------|
| A new `/v1/*` route is registered without a commercial class. | High | Add a policy coverage test that iterates `getOpenAIRoutes()` and fails on missing/duplicate policy. |
| A passthrough, file, fine-tuning, batch, or assistant route reaches an upstream provider in production before billing/audit semantics exist. | High | Add production fail-closed wrapper that rejects disabled routes before handler dispatch. |
| Docs claim a route is supported while runtime disables it. | Medium | Generate/update a route table from the same classification vocabulary and assert docs contain class names and critical routes. |
| Non-production tests break because disabled routes stop registering globally. | Medium | Keep route registration intact and make fail-closed conditional on production policy. |
| Phase 13 overclaims v05 completion. | Medium | Summary and state updates must leave RELAY-10, RELAY-11, BILL-01, BILL-02, and DOC-04 open. |
</threat_model>
