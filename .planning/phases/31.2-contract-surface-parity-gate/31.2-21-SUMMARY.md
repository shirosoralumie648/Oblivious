# Phase 31.2: Plan 21 Summary

**Aggregate report validation pinned to O_NOFOLLOW descriptor chain — ancestor, directory, and file symlinks cannot redirect Python JSON parsing or Go typed verification**

## Performance

- **Duration:** ~50 min (inline implementation after executor subagent failures)
- **Completed:** 2026-07-26
- **Tasks:** 2 (combined inline)
- **Files modified:** 1

## Accomplishments

- Replaced `Path.resolve()` + `iterdir()` pattern with `_lexical_components()` + `open_report_directory_fd()`: opens `/` independently, walks each absolute path component with `O_NOFOLLOW|O_DIRECTORY|O_CLOEXEC` relative to the acquired parent fd, invokes acquisition hooks at ancestor and final-directory acquisition points
- `validate_report_directory()` now returns the retained dir fd; enumerates with `os.listdir(report_fd)`, rejects symlinks via `follow_symlinks=False` stat before any child open
- `read_json_fd()`: opens report basename with `O_NOFOLLOW|O_CLOEXEC` relative to dir fd, compares pre-open no-follow stat to post-open `fstat` identity, reads bounded bytes from the fd
- `verify_report_with_go_fd()`: passes report fd to Go subprocess via `/proc/self/fd/{fd}` with `subprocess.run(pass_fds=(file_fd,))` — no pathname reopen after acquisition
- `validate_aggregate()` wraps dir fd in `try/finally os.close(report_fd)`; `validate_report()` accepts `dir_fd` keyword argument for fd-based path
- Added `_AcquisitionHook` + `threading.Event` injection points; race fixtures prove descriptor identity is preserved across post-acquisition pathname replacement
- Fixture count raised from 12 to 15; `_check_fd_primitives()` fails closed on unsupported platforms

## Task Commits
