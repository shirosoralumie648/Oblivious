## Trust Boundaries

| Boundary | Description |
|---|---|
| producer report directory -> aggregate | Concurrent or caller-controlled filesystem entries can redirect trusted reads. |
| root/ancestor traversal -> final report directory | Replacing an already traversed pathname must not redirect later component opens. |
| report-directory validation -> enumeration/read | Replacing the final pathname must not redirect exact-set checks or child opens. |
| Python JSON validation -> Go typed verification | A second pathname open can validate bytes from a different file identity. |
