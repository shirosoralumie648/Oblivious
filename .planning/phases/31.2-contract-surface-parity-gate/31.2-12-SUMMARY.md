## Decisions Made

- Every Group B transport references a concrete named generated operation constant. Shared helper functions only select codecs from that supplied operation; they do not reconstruct method, path, media, schema, or status identity.
- Optional-body POST operations retain their existing public API behavior while their encoder identity comes from the generated operation. No placeholder body is fabricated for no-body calls.
- MCP add-server and execute-tool serializers select only documented business fields. A regression passes forged `capabilityId` members and proves they do not reach the HttpClient mutation payload.
- Admin dashboard fetching now uses the shared typed SWR transport tuple, so `getAdminStatsOperationContract`, request encoder, and response decoder all reach the actual transport owner.
