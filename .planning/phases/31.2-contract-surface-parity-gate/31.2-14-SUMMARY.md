## Decisions Made

- Production code calls only `register*RouteSurfaces`; legacy `register*Routes(*ServeMux, ...)` adapters create local registrars for focused behavior tests and contain no metadata or direct mount authority.
- Crossing ServeMux patterns use one separately tracked physical catch-all whose internal table retains every logical path and composed handler. It dispatches only on exactly one match and otherwise returns an authenticated fail-closed 404.
- Registrar snapshots continue to report the exact logical method/path mounts even when Go ServeMux requires a physical bridge, so implementation mechanics cannot change contract identity.
- Group B manifest discovery starts from the eight owner operation sets and exact method/path keys. Manifest JSON remains compare-only and cannot construct handlers, middleware, auth, guards, or mounts.
