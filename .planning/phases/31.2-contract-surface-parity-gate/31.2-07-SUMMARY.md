## Decisions Made

- The ledger version is the complete migration filename because that is the identity persisted by live `migrations.Apply`; historical duplicate numeric prefixes remain ordered by filename.
- Static-to-ledger equality is an exact `MigrationIdentity` row comparison. Filename and disposition facts are separately hashed and cannot be requested from runtime ledger evidence.
- The static command has no DB dependency. The ledger command opens PostgreSQL only from a validated environment-variable name, pings it, reads ordered rows, and never applies or replays migrations.
- CLI success/error output omits repo paths, output paths, SQL, DSNs, and raw underlying error strings.
