  <files>scripts/deploy-validate.sh</files>
  <action>
  Run the migration binary against the compose database before declaring the stack ready and before running smoke.
  </action>
  <implementation_contract>
  - Keep Docker prerequisite checks and existing restricted-network diagnostics.
  - After `docker compose up -d postgres redis`, run `docker compose run --rm oblivious-server /usr/local/bin/oblivious-migrate` with the same compose environment.

  </implementation_contract>

<task type="tdd">
  <name>Task 3: Add Kubernetes validation script</name>
  <files>scripts/k8s-validate.sh</files>
  <action>
  Create a Kubernetes validation entrypoint that applies manifests, waits for rollouts, port-forwards the server service, and runs the shared smoke.
  </action>
  <implementation_contract>
  - Start with `#!/usr/bin/env bash` and `set -euo pipefail`.
  - Require `kubectl`; if absent, print `[k8s-validate] kubectl is required` and exit `127`.
  - Require a reachable current context with `kubectl cluster-info`; if unavailable, exit non-zero with `[k8s-validate] kubernetes cluster is not reachable`.
  - Require `OBLIVIOUS_K8S_SECRET_FILE`; if missing, print instructions to copy/fill `deploy/kubernetes/secret.example.yaml` outside git and exit `2`.
  - Refuse to use `deploy/kubernetes/secret.example.yaml` as the secret file for proof.
  - Apply namespace first, then the secret file, then configmap, Postgres, Redis, server, and web manifests.
  - Wait for `deployment/oblivious-server` and `deployment/oblivious-web` rollout status in namespace `oblivious`.
  - Port-forward `service/oblivious-server` to `${OBLIVIOUS_K8S_PORT:-18080}`, run `BASE_URL=http://127.0.0.1:$port bash scripts/deploy-smoke.sh`, and clean up the port-forward process.
  - Support `OBLIVIOUS_K8S_CLEANUP=true` to delete the namespace after validation; default must not delete it.
  </implementation_contract>
  <verify_red>
  <automated>env -u OBLIVIOUS_K8S_SECRET_FILE bash scripts/k8s-validate.sh</automated>
  <expected>FAIL with `kubectl is required` on the current environment if kubectl is still missing; if kubectl is present, fail because `OBLIVIOUS_K8S_SECRET_FILE` is required.</expected>
  </verify_red>
</task>
