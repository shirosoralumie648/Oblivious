<threat_model>
<threat severity="high" mitigation="Use Relay embedder injection and keep provider calls out of Knowledge; test that indexing/retrieval uses the configured embedder.">
Knowledge can bypass the Relay billing/rate-limit/monitoring invariant if it calls embedding providers directly.
</threat>
<threat severity="high" mitigation="Require organization filters on chunk embedding writes and vector reads; add tests for cross-tenant denial.">
Vector search can leak another tenant's document chunks if organization scope is not part of retrieval.
</threat>
<threat severity="high" mitigation="Return explicit configuration errors when embeddings are unavailable instead of falling back to text search under RAG copy.">
The product can overclaim RAG while still returning keyword snippets.
</threat>
<threat severity="medium" mitigation="Return bounded citation fields and snippets; do not expose full document content in retrieval results.">
Citation payloads can leak more document content than the retrieval UI needs.
</threat>
</threat_model>
