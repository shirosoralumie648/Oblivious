<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Git checkout -> BuildIdentityV1 | Mutable filesystem and Git metadata become release identity. |
| linker/build args -> embedded provider | Build transport values enter a binary but remain untrusted until verified. |
| CLI/env -> trusted provider | Caller-controlled arguments/environment could attempt identity substitution. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-31-03-01 | Spoofing | Git/build identity | high | mitigate | Derive commit/tree from clean HEAD, recompute contract digest, validate exact shapes, and reject caller identity inputs. |
| T-31-03-02 | Tampering | embedded linker tuple | high | mitigate | Treat linker fields as untrusted and compare recomputed packaged-contract digest before returning identity. |
| T-31-03-03 | Elevation of Privilege | CLI operation profile | high | mitigate | Require explicit profile, reject default fallback/excluded profiles before runner calls, and test zero-call paths. |
| T-31-03-04 | Repudiation | identity failure | medium | mitigate | Stable structured codes and deterministic JSON identify missing/mismatch/dirty/contract failures. |
| T-31-03-05 | Information Disclosure | Git/CLI errors | medium | mitigate | Sanitize command errors to repo-relative context and stable codes; never echo environment values or contract secrets. |
</threat_model>
