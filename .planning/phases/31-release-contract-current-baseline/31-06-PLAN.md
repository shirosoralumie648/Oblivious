## Stage B post-commit clean HEAD gate

After the executor creates the atomic Phase 31 implementation commit and before any push, the executor must run this read-only command from the exact clean commit:

```bash
test -z "$(git status --porcelain=v1 --untracked-files=all)" && bash scripts/verify-release-contract.sh --clean-head --profile monolith
```

The executor records the resolver-confirmed deployment profile (`monolith`), exact `HEAD^{commit}`, `HEAD^{tree}`, contract digest, image tag, report path, pass/fail, empty skip list, and residual risks in `31-06-SUMMARY.md`. A failure requires a new fix commit and a fresh clean-HEAD run; the failed identity tuple/profile is never amended, overridden, or pushed.
