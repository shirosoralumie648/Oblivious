## Trust Boundaries

| Boundary | Description |
|---|---|
| authored JSON -> typed authority | Repository text becomes release commitment/profile policy. |
| profile operation metadata -> executable path | Contract path/argv may cause a child process in a later dispatcher. |
| Go module proxy -> validator dependency | External module bytes enter a security-critical parser. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-31-01-01 | Tampering | contract.v1.json/schema | high | mitigate | Duplicate-key rejection, strict schema, typed semantic closure, canonical committed authority, and negative mutation tests. |
| T-31-01-02 | Elevation of Privilege | profile commitment/default | high | mitigate | Enforce one committed monolith default and hard semantic rejection of candidate-profile promotion. |
| T-31-01-03 | Tampering | operation path/argv | high | mitigate | Restrict to executable real paths under `scripts/`, reject traversal/symlink escape, and preserve argv arrays. |
| T-31-01-04 | Information Disclosure | validation errors | medium | mitigate | Emit stable codes and sanitized IDs/paths only; never serialize credentials, DSNs, or raw target evidence. |
| T-31-01-05 | Tampering | JSON Schema dependency | medium | mitigate | Pin v6.0.2 in go.mod/go.sum, run `go mod verify`, and cover schema behavior with local negative tests. |
