## Trust Boundaries

| Boundary | Description |
|---|---|
| validated contract -> digest | A typed commitment becomes a shared release identity component. |
| contract operation ref -> OS process | Authored path/argv crosses into process execution. |
| test selector -> evidence claim | A regex chooses which behavior is claimed as tested. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-31-02-01 | Tampering | canonical digest | high | mitigate | Hash only validated normalized typed values; lock formatting invariance and semantic sensitivity with golden vectors. |
| T-31-02-02 | Elevation of Privilege | operation dispatcher | high | mitigate | Explicit profile, commitment-first checks, realpath allowlist, literal argv, minimal environment, injected zero-call runner tests. |
| T-31-02-03 | Spoofing | targeted test evidence | high | mitigate | List concrete tests first, reject invalid/zero selectors, and propagate the actual test status. |
| T-31-02-04 | Repudiation | operation failures | medium | mitigate | Stable typed error codes distinguish required/unknown/excluded/mismatch/path/runner failures. |
| T-31-02-05 | Denial of Service | canonicalization/listing input | low | accept | Contract reads are bounded in Plan 31-01 and test selection is developer-controlled; failures remain nonzero and observable. |
