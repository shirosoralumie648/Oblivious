- Replaced prefix wildcards, owner substring inference, raw marker discovery, capability inference, and `EffectID(descriptor.ID)` fallback with the sole exact `runtimeDescriptorSpecs` map.
- Expanded the strict manifest contract with `descriptorId`, `effectId`, `registrationSymbol`, `guardCall`, `effectCall`, and `configurationSelector`, while preserving strict JSON and EOF validation.
- Added Go parser/AST proof for exact registration identity and guard-before-effect order, including explicit local typed call paths.
- Made the contract, selected committed profile, matching `RuntimeAuthorities`, selected runtime configuration, and capability bindings mandatory for coverage.
- Kept independently reachable APIs classified without promoting them into the shipped monolith projection.
- Revision 1 enumerates source registrations before the specification join, so unknown registered descriptors become `effect_coverage_extra_static` while unused descriptor literals remain non-authoritative.
- Revision 1 keys methods by receiver and validates each exact descriptor literal/capability binding, preventing sibling descriptors and same-named receiver methods from lending evidence.
- Revision 2 carries the exact registered literal/helper-call provenance and resolved EffectID into known-ID validation, eliminating the remaining constructor rescan and generated-row heuristic paths.
- Revision 3 makes selected runtime configuration mandatory, enforces all-or-none optional cohorts and exactly one web-search provider, rejects statically false or shadowed receiver proofs, and sorts descriptor/selector failures deterministically.
- Revision 4 binds resolver/registrar identity to exact AST objects, excludes statically unreachable registration/helper paths, and tracks the latest reaching scalar or collection state before consumption.
- Revision 5 adds scope-exact scalar and collection reaching definitions: inner shadow bindings cannot lend evidence to an outer Register/range, and unknown-condition writes, resets, or appends are rejected unless every path has the same proven state.
- Revision 6 makes loop provenance conservative: unknown or empty Range bodies cannot create definite membership, `For.Post` participates in scalar and collection reaching state, and ambiguous loop-carried writes fail closed.
- Revision 7 makes loop-body control explicit: `break`, `continue`, `goto`, `fallthrough`, and successful returns before a descriptor write/consumption invalidate provenance instead of allowing later lexical statements to certify it.
- Revision 8 rejects labeled or nested-loop continues even when they reuse the optional-sandbox condition; only the exact direct unlabeled production continue is permitted.
- Revision 9 rejects shadowed effect/error names, unrelated errors, and errors from another Resolve result; the sandbox exception now requires one exact same-row authority binding.
- Revision 10 rejects stale earlier Resolve evidence when the same error, or the same capability/error pair, is overwritten before the sandbox condition.
- Revision 11 treats any later reachable write to the selected error or capability object as stale/ambiguous, including ordinary assignments and tuple writes that are not themselves Resolve bindings.
- Revision 12 rejects later writes that mutate the current Range row object or its selector, including direct, tuple, and conditional row writes after the selected Resolve binding.
- Revision 13 rejects taking the address of the current Range row or its selector between Resolve and descriptor construction, covering helper calls, local pointer aliases, and conditional helper escapes without relying on alias analysis.
- Revision 14 extends that escape barrier to the current loop/declaration start, rejecting row, selector, and conditional helper aliases created before the authoritative Resolve.
- Revision 15 treats any method call whose receiver/root is the current row or selector as an implicit escape across the same window, while preserving plain field reads and the production projection.
- Revision 16 treats current-row-rooted selector values as implicit escapes unless AST context proves the exact `effect.id` Resolve/comparison read or production `effect.key` capability-map index.
