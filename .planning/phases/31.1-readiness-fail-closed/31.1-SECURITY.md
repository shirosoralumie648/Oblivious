## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Authored release contract to runtime authority | Trusted identity, explicit profile, catalog bindings, and timing become dynamic authorization inputs. | Release identity and capability policy |
| Dependency probes and clock to readiness generation | Bounded observations determine immutable current availability. | Health observations and timestamps |
| Untrusted request or persisted work to effect consumer | Every Provider, tool, worker, and financial effect must re-resolve server authority and recheck current readiness. | Tenant requests, jobs, model/tool subjects |
| Runtime authority to evidence surfaces | Reports and audit files serialize runtime state without becoming authorization inputs. | Readiness observations and release evidence |
| Source identity to image and deployment assets | One clean source tuple binds binaries, labels, contract, profile, probes, and report identity. | Build identity and deployment configuration |
| Signed provider event to reconciliation | Prior external truth may update local state but cannot authorize a new outbound financial effect. | Signed event identity and local transition |
