<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| authenticated checkout -> local intent/provider | A request can create durable financial identity and an external payment session. |
| queued payout -> payout provider | Persisted queue state is not proof of current authorization or successful dispatch. |
| signed provider event -> local reconciliation | Prior external truth may update local state but cannot authorize a new outbound effect. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-RDY-08 | Elevation of Privilege | checkout/payout dispatch | high | mitigate | Guard before intent and each provider attempt, zero-call spies, and non-dispatched state assertions. |
| T-RDY-08 | Repudiation | provider reconciliation | high | mitigate | Signed/replay-checked event identity, idempotent local transition and no outbound method on reconciliation interface. |
| T-RDY-03 | Elevation of Privilege | cached ingress/generation | high | mitigate | Per-attempt current guard plus shared effect descriptor registration; no generation pinning. |
</threat_model>
