```go
const DeploymentSurfaceID = "deployment"
type DeploymentDetails struct {
    Profile           string `json:"profile"`
    CanonicalWorkload string `json:"canonicalWorkload"`
    StartupEndpoint   string `json:"startupEndpoint"`
    LivenessEndpoint  string `json:"livenessEndpoint"`
    ReadinessEndpoint string `json:"readinessEndpoint"`
    AuditStorage      string `json:"auditStorage"`
    MigrationState    string `json:"migrationState"`
    HarnessResult     string `json:"harnessResult"`
}
func NewDeploymentReport(context.Context, buildinfo.IdentityProvider, releasecontract.ProfileResolver, string, string, string, string, DeploymentDetails, surfacereport.Outcome) (surfacereport.SurfaceReportV1, error)
```

The constructor's string arguments are explicit `repoRoot`, `contractPath`, `schemaPath`, and `profileID`, in that order. It accepts no caller identity/digest/commit, readiness generation/times, target claim or skip override.

The harness has two exact modes. `standalone-build` remains the independently runnable D-RDY-26 proof and invokes the Phase 31 builder once. `aggregate-consume` requires `--artifact-bundle <release-artifact-bundle/v1.json> --image-tag <tag> --image-digest <sha256:...>`, verifies the bundle identity/tag/digest against the existing local immutable image, and records a build invocation count of zero. The bundle is transient and is created once by the Phase 31.2 release session; a missing bundle, tag/digest mismatch, mutable tag resolution, or any attempted rebuild is a hard failure.
