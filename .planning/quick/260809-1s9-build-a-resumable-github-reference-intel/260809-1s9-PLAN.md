# Quick Task 260809-1s9: Reference GitHub Intelligence

## Task 1: Define the evidence contract

Create a deterministic repository discovery and raw-record contract for issues, merged pull requests, releases, tags, and local changelog files. Preserve repository, source URL, source ID, timestamps, state, and a canonical content hash. Treat issue claims as unproven unless they link to a merged pull request, closing commit, or release evidence.

## Task 2: Implement resumable collection and Luna cleaning

Implement a standard-library Python CLI with `discover`, `collect`, `clean`, `aggregate`, and `run` commands. Use `gh api --paginate` for GitHub data, bounded concurrency for collection, one-record Luna calls through `codex exec --model gpt-5.6-luna`, atomic writes, retry/backoff, and per-record output files so interrupted runs resume without repeating completed work.

## Task 3: Verify and document the pipeline

Add fixture-driven unit tests for origin parsing, normalization, evidence classification, checkpoint resume, and aggregation. Smoke-test live collection against one reference repository and one real Luna record outside git. Document credentials, commands, evidence limits, costs, work-directory layout, and the explicit distinction between reference capabilities and Oblivious implementation.
